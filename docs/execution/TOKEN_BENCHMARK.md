# Controlled portable-DAG token benchmark

The benchmark retains the naive full-context comparator and the dependency-routed
challenger as separately pinned artifacts. Every lane binds the same acceptance
criteria, authority, subject snapshot, model route, and budget. Only
provider-measured or tokenizer-measured input counts qualify; static estimates and
unavailable values do not become zeros. The checked reference fixture constructs the
exact naive and routed text, hashes both byte streams, and measures them with the
versioned deterministic `hive-mind-portable-lexical-tokenizer-v1` regex. It is a
portable token-unit benchmark, not a claim about any provider's billing tokenizer.

The candidate threshold is a 30% aggregate input-context reduction with positive
savings in every retained lane across repository, monorepo, research-artifact, and
workflow subjects. Repetitions and every losing lane remain in the report.

Each lane also binds one accepted synthetic claim inventory, and the five
repetitions are deterministic reproductions of the same exact bytes. Meeting the
threshold establishes only `MEASURED_LOWER_INPUT_CONTEXT` for this controlled
synthetic fixture. It does not establish product superiority, equal model-output
quality, provider-token savings, improved outcomes, production readiness, or A5
readiness.
