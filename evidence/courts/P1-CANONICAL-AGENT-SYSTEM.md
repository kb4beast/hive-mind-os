## Advocate case

A versioned canonical definition with deterministic projections can eliminate
manual drift while preserving the v1 facade. Independently versioned skills
permit reuse without collapsing role or judgment identity. Generated host
artifacts can expose explicit degradation rather than pretend host parity.

## Cross-examination and dissent

One canonical source is a high-value compromise point. Generated churn can hide
harmful changes. Requested capabilities can be mistaken for grants. Host
projection cannot guarantee behavioral equivalence. Larger prompts are not
better behavior. The unidentified Armory source, unverified hosts, source
docket gaps, extension signatures/isolation/activation, and independent package
promotion remain blocked.

## Architecture, evaluation, and rollback

Candidate decision: ADR-018. Phase 2 adds v2 records without selecting them.
Shadow evaluation freezes task, evidence, memory, provider/model policy, tools,
budgets, stop conditions, and metric version. Each role must pass absolute
behavior, authority, privacy, trust, recovery, and customer-value gates before
relative comparison.

Rollback selects the prior independently verified definition and regenerates
its projections; losing challengers, dissent, fixtures, and receipts remain.
