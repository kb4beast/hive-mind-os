# P13 Benchmark Court Results

This report is generated from the committed raw JSONL for the first complete P13 run.
Until that run is recorded, no measurement is available. The only permitted P13
disposition is `measurement-recorded`; this single-family, single-baseline harness
authorizes no comparative quality or superiority claim.

The completed report records the run identifier, corpus digest, code commit, fixed seed,
repetition count, per-lane success rates, seeded bootstrap 95% confidence intervals, and
the append-only evidence location. Failed and losing attempts retain the same four raw
artifact classes as successful attempts.
