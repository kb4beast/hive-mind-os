## The methodological problem this run has, stated first

Tournament B's heaviest criterion is `whitespace_uncontested` at 0.20, and it is
scored from **failure to find** a competitor in a web search. Absence of evidence
in a search index is weak evidence of absence. A stealth startup, a corporate
internal programme, a university spinout, or anything not indexed will not appear.
So every whitespace score in this run is a **hypothesis with a confidence level,
not a finding**, and the execution DAG opens with a node whose only job is to try
to disprove them properly (patent search, SBIR award database, trade press,
Cameron County and FAA filings, and asking ExF directly, since they would know).

Treat "nobody is doing this" as the claim most likely to be wrong in this
document. It is also, unavoidably, the claim the user asked for.
