## Material implementation decision

Phase 1 requires one repository policy change: `.obsidian/` is ignored so a
user can open the repository as a vault without accidentally committing local
settings, workspace state, plugins, caches, or machine paths.

No production runtime change is required or permitted. The candidate changes
no `src/hive_mind_os` file, schema, package resource, prompt, stored-state
shape, provider behavior, CLI parser, public facade, host adapter, exporter,
memory writer, projection writer, or champion pointer.

## Cross-examination and dissent

The strongest objections are retained:

- a canonical definition or memory authority is a high-value compromise
  target;
- static source matching cannot prove arbitrary Python, native, reflected,
  subprocess, remote, or operating-system effects;
- the Generation Zero event and store model still lacks cross-store
  transactions, full replay, privacy classification, repository identity, and
  provider-native usage;
- Obsidian projection can expose secrets, become stale, conflict with human
  edits, or recursively re-enter discovery;
- native usage normalization can double count, lose missingness, leak data,
  or enable evaluator gaming;
- standards and research references may drift or fail to generalize;
- exact Armory semantics and AgentTelemetry content remain unadmitted;
- no host, plugin, memory system, telemetry exporter, or redesigned agent is
  implemented or supported; and
- Windows blockers and repository-governance blockers remain outside this
  Phase 1 architecture scope.

These objections block runtime activation and broad completeness/superiority
claims. They do not block adoption of contracts that explicitly turn each
objection into a fail-closed Phase 2/3 acceptance gate.

## Rollback and appeal

Rollback is the exact procedure in
`docs/architecture/PHASE1_ROLLBACK_PLAN.md`. It reverts only the completion
commits on the draft PR branch, regenerates and verifies the retained
Generation Zero evidence, and never deletes local `.obsidian/` state or
historical court/source records.

Any new evidence may appeal a source or architecture disposition. The prior
and losing disposition remains in Git. A Judge cannot hear an appeal of its
own ruling.
