# P4D-001 — Explorer idea lifecycle reference-event court

## Proposition

May Hive Mind OS add a package-private, private-by-default bridge that retains
digest-bearing encounter, relationship, court, experiment, and outcome references as
existing append-only memory records without claiming artifact truth or lifecycle
completion?

## Identities and testimony

- Explorer/Clerk/Advocate `/root/phase4d_explorer` recommended narrow `adapt`.
  Existing OpportunityLedger, Foundation memory, public release, cognitive notes,
  and Obsidian paths should be reused rather than duplicated.
- Architect/Cross-Examiner `/root/phase4d_architect` rejected direct private-ledger
  projection, a new lifecycle database, OpportunityLedger-integrated memory writes,
  and silent mutation of the v1 four-Base view contract. It recommended append-only
  reference events, separate memory authority, exact public-release binding, and
  semantic relationship identities independent of SQLite row count.
- Builder `/root` produced exact implementation `3024bae` with seven focused tests.
  It is package-private, uses `memory-record-v1`, defaults private, preserves
  `pinned-unverified` and unknown-stage semantics, and authorizes no comparison,
  value, promotion, or activation.

Independent adversarial and Curator testimony remain pending. The proposal is not
yet judged.

Independent Cross-Examiner `/root/phase4d_cross` and Curator

not close those fail-closed defects.

through the compiler and require exact memory equality; validates built-in,
printable, NFC-normalized scalars before enum use; and requires timezone-aware
ISO-8601 timestamps. The exact attacks are regression cases. Independent closure is
pending.

Builder repair `58c4195133edddf049b697b40bd5766ae1549f16` validates the complete
