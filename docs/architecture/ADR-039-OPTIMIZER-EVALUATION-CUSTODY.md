# ADR-039: Optimizer evaluation custody

- Status: adapted bounded record
- Phase: 5G

Optimizer governance separates sealed holdout custody, pinned comparator manifests, immutable losing
results, evaluator identity, and promotion judgment. Empty or `not-run` records are preferable to
fabricated evidence. The current challenger remains proposed; holdout access, evaluation,
superiority, learning, promotion, and champion mutation remain prohibited.

Future evaluation may append results only when comparator versions, budgets, seeds, datasets,
regression thresholds, evaluator authority, and rollback are exact. Losing results cannot be
deleted. A procedural defer court cannot substitute for an authenticated independent evaluator.
