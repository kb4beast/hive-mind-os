# Changelog

All notable user-facing changes are recorded here.

## Unreleased

## 0.7.0 - 2026-08-03

### Added

- The offline `hive-mind demo` command, which produces a deterministic fixture-repair receipt bundle.
- Standalone `hive-mind verify` for a committed local change and a sealed acceptance specification.
- A documented, one-approval contribution path for documentation and typo corrections.
- Contributor, conduct, and security guidance plus issue and pull-request templates.

### Changed

- The README now leads with the verification-first product positioning and a 60-second offline demo.

### Distribution

- Published as a GitHub-only prototype release. PyPI publication is deferred because this repository has no
  configured publishing workflow and the project does not claim release or production readiness.
