# Security Policy

## Supported versions

Security fixes are made against the current `main` branch. The latest released version is
supported when a release exists.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue. Use the repository's
[private security advisory form](https://github.com/kb4beast/hive-mind-os/security/advisories/new)
instead. Include a clear description, affected version or commit, reproduction steps, and
any proposed mitigation.

The maintainer will acknowledge the report, assess impact, and coordinate a fix or
responsible disclosure through the advisory. Please allow time for that process before
making the issue public.
