## 2. Subject resolved

The requested system is interpreted as an operating system that can take a bounded objective,
discover evidence, design, implement, verify, integrate, operate, measure, learn, repair itself,
and resume after interruption without a human carrying context between roles.

The first prompt’s specific concern is incorporated as a hard acceptance contract:

1. all eight roles must be operationally wired, not merely declared;
2. a role that believes it needs a human must consult applicable roles first;
3. suspected cheating must be independently challenged with evidence;
4. software defects and missing evidence become autonomous work, not owner questions;
5. only genuine external authority may escalate; and
6. same-model role passes must never be represented as independent humans.

## 5. Role-first resolution before humans

### 5.1 Required resolution order

1. classify the question;
2. inspect deterministic repository/state evidence;
3. consult at least two applicable roles;
4. preserve dissent and adverse evidence;
5. create repair, evidence, remand, replan, or quarantine work where applicable;
6. escalate only if an external authority class remains; and
7. ask for the minimum bounded authority, not a broad human solution.

### 5.2 Genuine authority classes

- credential or secret;
- legal or regulatory signoff;
- financial spend;
- production access;
- protected-branch merge;
- owner value choice where evidence cannot define the value judgment;
- personal consent; or
- external contractual commitment.

Ambiguity, a failing test, a software bug, missing evidence, missing acceptance, provider failure,
or suspected cheating is not a human authority class.

### 5.3 Cheating classes

The plan treats test weakening, sealed-evaluator leakage, target/future access, self-grading,
self-promotion, fabricated or stale receipts, selective evidence, authority expansion, metric
gaming, benchmark overfitting, friendly role selection, consultation theater, and concealed
dissent/failures as executable adversarial cases. Confirmed cheating quarantines work. Unresolved
cheating cannot become success.
