# Coupon Hive Privacy Notice

- Effective date: September 14, 2026
Version: 0.1.0 draft

## Summary

Coupon Hive 0.1.0 is a skills-only plugin. The publisher does not operate a server, user account system, database, analytics service, advertising system, or affiliate tracker for this version. The publisher does not receive or retain the user's chats, WatchSpecs, searches, or scheduled-task data through a Coupon Hive backend.

## Data used by the host

Coupon Hive uses information the user chooses to provide in the active ChatGPT or Codex conversation, such as:

- the physical item, free public activity or event, coupon, or manufacturer freebie sought;
- country, region, city, or an optional user-chosen postal code;
- currency, budget, merchant preferences, accepted offer conditions, and deadline;
- cadence, timezone, quiet hours, notification threshold, and stopping rule for a requested watch;
- an eligibility assertion such as “student offers are acceptable,” without proof or identifiers.

The OpenAI host processes the conversation under its own terms and privacy controls. When the user creates a ChatGPT Scheduled Task or Codex automation, the host stores the prompt, schedule, and related execution state. When web search is used, queries and page requests are handled by the host and relevant web sources under their applicable policies.

## Data minimization

Coupon Hive asks for the coarsest location useful to the search. Do not provide a full street address, payment card or bank information, passwords, one-time codes, government identifiers, health information, or eligibility documents. The skill is instructed not to request those categories.

Task titles should not contain sensitive product or service details. Search queries should not include unnecessary personal information.

## Publisher collection, retention, and sharing

- Publisher collection through a Coupon Hive backend: none in version 0.1.0.
- Publisher retention period: zero days because no Coupon Hive backend receives the data.
- Publisher sale of personal data: none.
Publisher advertising use: none.

This notice does not describe OpenAI's or a visited website's independent processing. Use the privacy controls and deletion features of those services.

## Voluntary support reports

If a user voluntarily opens a GitHub issue, GitHub and the repository maintainers receive the information in that issue. Public issues and their edit history can remain visible under GitHub's and the repository's policies; they are not covered by the zero-day Coupon Hive backend statement above. Do not include personal, payment, credential, location, or identity data. Use the issue tracker's controls or contact the maintainers to request correction or removal where available.

## User controls

Users can manage or delete conversations and can update, pause, or delete ChatGPT Scheduled Tasks or Codex automations using the host product's controls. Removing the plugin may not remove recurrence already created; manage it separately.

## Future versions

A future version that adds a remote MCP service, account, analytics, proprietary feed, or affiliate program requires a new notice before release, explicit consent where required, least-privilege authorization, retention and deletion controls, and cross-user isolation tests.
