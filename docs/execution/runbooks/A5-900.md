# A5-900 — Qualify governed-full autonomy behind external security/legal/operational gates

Round R12 (level 15), released ALONE. Branch `autopilot/a5-900`. Tier T4, risk
critical; category `promotion`. This is the maximum blast-radius node in the DAG and
its rationale is explicit: **production authority, spending, legal commitments, and
protected changes are genuine human/governance decisions, not role-resolvable
questions.** Like A4-800, the expected terminal state — unless authenticated external
sign-offs actually exist — is a complete, verifiable READINESS RECORD that ends in an
explicit "gates open / gates closed" adjudication, with every closed gate escalated,
never argued around. A5 qualification means the *procedure and evidence* for
governed-full autonomy are proven; it never means autonomy is switched on.

## 1. Contract summary

**Objective.** Qualify governed-full production autonomy only after external
security, legal, operational, and owner gates.

**Acceptance criteria (compressed).**
1. Independent security and operational reviews pass (independent = not the authoring
   role, per G8 truth boundary: agent role separation is procedural, not a claim of
   independent human review).
2. Owner/legal/production authority gates are explicit and authenticated.
3. Rollback, incident response, evidence retention, and stop mechanisms are proven
   (locally exercisable ones exercised; externally gated ones mapped to their gate).
4. No autonomous expansion of authority is possible (audited boundary).

## 3. Design — readiness court, gate matrix, exercises

```
evidence/pilots/a5/
  readiness-court.json         # the adjudication record (schema below)
  gates/gate-matrix.json       # one row per external gate, status + authority cite
  exercises/
    recovery-exercise.json     # local production-recovery rehearsal transcript
    stop-mechanism.json        # demonstrated stop + rollback of the exercise itself
  audits/authority-boundary.json  # no-authority-expansion audit
  tests/                       # focused-test transcripts
  summary.json                 # node receipt data (same boilerplate as A3/A4)
docs/execution/A5_GOVERNED_FULL_READINESS.md
```

**`gates/gate-matrix.json`.** One row per gate; rows are exhaustive over (a) G1–G8
from `HUMAN_AUTHORITY_GATES.md`, (b) every `open` blocker in `BLOCKERS.md`, and
(c) the five contract escalation conditions. Row shape:
`{"gate": "G5-production-pilot", "kind": "production_access", "status": "closed",
"authority": "HUMAN_AUTHORITY_GATES.md — owner decision 2026-08-04: 'No production
pilot is authorized.'", "authenticated": false, "escalation": "production_access
required", "what_would_open_it": "..."}`. A row may be `"status": "open"` ONLY with
an authenticated external authority record (an owner statement in the live session,
or a receipt committed by the owner) — never by agent reasoning. With today's
recorded owner decisions, expect every production-facing row to be `closed`.

**`readiness-court.json`.** Fail-closed adjudication bound by digests:
`{"node": "A5-900", "base_commit": "<40-hex>", "exhibits": [{"path": "...",
"sha256": "..."} ...] (must include the gate matrix, both exercises, the authority
audit, the A4 summary, and the focused-test transcripts), "roles": {"author":
"codex:a5-900-worker/orchestrator", "reviewers": ["codex:a5-900-curator",
"codex:a5-900-steward"]}, "independence_disclosure": "separately prompted agent
identities; procedural separation only, per G8 this is NOT independent human
review", "verdict": "not-ready" | "ready-behind-gates", "closed_gates": [...],
"dissent": [...], "court_digest": "<sha256 of canonical record minus this field>"}`.
The only verdicts allowed: `not-ready` (any closed gate whose kind is security or
operational and locally satisfiable) or `ready-behind-gates` (all locally
satisfiable work proven; remaining closed gates are exactly the external ones).
There is NO "ready" verdict — that word is reserved for humans opening the gates.

**Security and operational reviews (criterion 1).** Two review records inside
`readiness-court.json` `"reviews"`: a security review (checks: no credential values
in evidence, forbidden scopes untouched across A3/A4/A5 branches, B-OPS-06 hard
isolation still open ⇒ noted as closed gate) and an operational review (checks:
stop/rollback procedures exercised, evidence digests verify, focused tests green).
Each authored by a differently-prompted role identity than the author, with the
independence disclosure above. If a review FAILS, fix within scope or record the
failure and verdict `not-ready` — never soften a check to pass.

**`exercises/recovery-exercise.json` (criterion 3, local rehearsal).** In a temp
directory OUTSIDE the repo: clone this repository fresh
(`git clone <local-repo-path> <tmp>/a5-recovery`), check out the release branch,
simulate loss (delete the clone), re-clone, and verify: `git rev-parse HEAD` matches,
and one retained evidence artifact re-verifies byte-for-byte (recompute the SHA-256
of `evidence/pilots/a4/pilot-plan.json` and compare to the digest recorded in the A4
doc). Record every command, exit code, and digest. `exercises/stop-mechanism.json`:
demonstrate the stop path on the exercise itself — interrupt a step, record state,
resume, and show no duplicate or lost evidence. Production-scale retention/incident
response remain gate-blocked (B-GOV-04, B-OPS-04) and are recorded as such, mapped
to their gate rows — the exercise proves the *procedure*, the gate row owns the
*production claim*.

**`audits/authority-boundary.json` (criterion 4).** Evidence that no autonomous
authority expansion is possible: (a) transcript of the focused authority/governance
tests (Section 5); (b) a scan proving no file under `evidence/pilots/a5/**` or the
A5 doc grants, requests, or embeds any credential, spend, merge, or production
authority; (c) confirmation that forbidden paths (`.github/governance/**`,
`CODEOWNERS`, `HARDENED_VISION_CONTRACT.md`) are untouched on the node branch
(`git diff --name-only <base>..HEAD` intersected with forbidden scope is empty);
(d) the statement that every gate-opening act in the matrix requires a human act
outside agent control, with the matrix row as proof.

**Document.** `docs/execution/A5_GOVERNED_FULL_READINESS.md` (~120–200 lines):
what governed-full means and does not mean; the gate matrix rendered as a table;
the court verdict and its digest; the recovery/stop exercise narratives; the
owner-facing "how a human opens each gate" section (per gate: who signs, what
artifact they produce, where it is recorded — citing G1–G8 rows); and an explicit
non-claims section (no production readiness, no release readiness, no superiority —
B-OPS-04 `release_ready=false` and B-OPS-05 quoted).

5. Push `autopilot/a5-900`; open a DRAFT PR to `main`. Stop. If the verdict is
   `not-ready`, the PR still opens — the truthful record IS the deliverable.
