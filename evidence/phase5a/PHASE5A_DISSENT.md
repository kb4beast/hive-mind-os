# Phase 5A dissent

The following dissent is controlling and must accompany any use of the candidate.

1. **Procedural roles are not independent actors.** One assistant simulated the role purposes.
   No authenticated identity, blind workspace, independent model, or external reviewer was
   created by labels in a JSON document.
2. **A valid plan is not executed work.** The candidate cannot call a provider, tool, host,
   scheduler, Git adapter, or agent. It cannot create work items in an active store.
3. **Budget plans are proposals, not enforcement.** No physical token, money, time, compute, or
   tool lease is issued or reconciled.
4. **Dependency completeness does not establish plan quality.** The full transitive closure
   prevents skipped predecessor roles but does not prove that the instructions solve the user
   problem.
5. **Caller evidence labels are not verification.** Empty evidence is `unknown`; incomplete
   caller claims are `claims-incomplete`; complete caller claims are `claimed-unverified`. Phase 5A has no
   authenticated evidence verifier and cannot produce a `verified` status.
6. **Scope and digest integrity are not external authenticity.** Request, objective, tenant,
   repository, work-item, output, and plan bindings detect local drift, but do not prove the
   source request or actor identity was authentic.
7. **No learning or champion migration exists.** The candidate records no outcomes, report
   cards, teaching packets, promotion, demotion, or rollback decision.
8. **No release readiness.** `B-OPS-09`, P20, authenticated governance, live host conformance,
   and production operations remain outside this slice.
9. **Digest integrity is not resistance to a privileged coherent rewrite.** Canonical hashes
   detect drift in the selected bytes; a privileged attacker who can rewrite code and evidence
   coherently remains outside this local structural guarantee.

The allowed disposition is therefore no stronger than `adapt` for a draft, inert,
package-private candidate pending exact-head hosted verification and future independent courts.
