# Coupon Hive legacy Custom GPT configuration

This compatibility package is for an eligible managed Business, Enterprise, or Edu workspace that still permits new GPT creation. As of September 14, 2026, OpenAI's current retirement notice says personal Free, Go, Plus, and Pro accounts cannot create or publish new GPTs. Confirm current workspace policy before using the builder.

Scheduled Tasks are not supported in Custom GPT conversations. This GPT can interview, search, verify, and produce an inert ready-to-paste recurrence draft, but the user must paste it into a regular ChatGPT chat with Scheduled Tasks or use it for a separate Codex automation. That destination must resolve and show its exact host payload and obtain fresh confirmation before creating or changing anything; approval in the GPT does not transfer across surfaces.

## Builder fields

Name:

    Coupon Hive

Description:

    Finds current deals and genuine freebies, explains hidden conditions, and turns your approved search into a ready-to-schedule low-noise watch.

Instructions:

Upload or paste the entire contents of INSTRUCTIONS.md into the Instructions field.

Conversation starters:

1. Interview me and find the best currently verifiable deal for something I want.
2. Help me define what free means, then find genuine freebies near me or online.
3. Turn my shopping request into a quiet recurring watch prompt.
4. Check whether this coupon is current and explain every restriction.

Knowledge:

Upload KNOWLEDGE.md.

Capabilities:

- Web search: on.
- Code Interpreter and Data Analysis: off for the minimum-permission release unless a separate use case is reviewed.
- Image generation: off.
- Canvas: optional; not required.
- Apps or Actions: none in version 0.1.0.

Recommended model:

Use the workspace's current general-purpose default. Do not pin a model name in the listing unless the publisher has run the complete evaluation suite with it.

Icon:

Upload icon.png. Review the circular crop before saving.

## Before any external builder action

- Review the icon, exact listing text, and knowledge file.
- Confirm the workspace is eligible to create and share a GPT.
- Obtain action-time confirmation before entering or saving public-facing content.
- Do not claim Scheduled Tasks work inside the GPT.
- Do not claim “ultimate,” “best,” exhaustive coverage, guaranteed savings, or Store publication.
- A public save or share is subject to current workspace policy and OpenAI review.

For the current universal Store path, use the skills-only plugin at plugins/coupon-hive instead of this compatibility package.
