# Coupon Hive Support

For bugs, inaccurate classifications, and accessibility problems that contain no sensitive security details, use the Hive Mind OS issue tracker:

https://github.com/kb4beast/hive-mind-os/issues

Report suspected vulnerabilities privately through GitHub Security Advisories; do not open a public issue:

https://github.com/kb4beast/hive-mind-os/security/advisories/new

Include the Coupon Hive version, the behavior you expected, the behavior observed, and a public source URL when relevant. Do not include passwords, one-time codes, payment details, full addresses, government identifiers, private eligibility documents, exploit secrets, or other sensitive personal data in a public report.

For an offer that changed after a report, include the original verification timestamp. A stale merchant offer is not evidence that the earlier observation was fabricated, but it is useful reliability feedback.

This support page is a repository draft. The public URL and a monitored support process must be verified before submission.
