# N05–N08 implementation receipt

This implementation tranche adds inert, fail-closed interfaces only. It does not
claim a live provider route, installed isolation runtime, external grant, fresh
process qualification, or independent Curator result.

- N05: `campaign_context.py` compiles subject/snapshot-bound capsule deltas and
  validates content-addressed cold expansion.
- N06: `validation_policy.py` binds cache admission to tenant, trust domain,
  adapter, policy, check purpose, and optional live-state freshness.
- N07: `campaign_routing.py` selects only data-policy-compatible admitted routes
  and tracks bounded repair attempts. Missing routes remain typed blocks.
- N08: `cortex/repository/mission_bindings.py` defines a strict immutable host
  descriptor. `workers.configured_mission_bindings_provider` must be invoked by
  an admitted host startup path with its resolver; no scheduler payload names an
  executable or supplies credentials.

Focused tests were authored in this tranche but not run under the owner-directed
implementation-first campaign mode. External host configuration, real adapters,
and fresh-process execution remain explicit qualification obligations.
