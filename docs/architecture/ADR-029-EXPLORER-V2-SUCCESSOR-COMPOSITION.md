# ADR-029: Explorer v2 successor composition

- Status: proposed for independent implementation court
- Date: 2026-07-30
- Base: `316ee55da4ea7449bcdb934ab442ef0d95f54ba5`
- Extends: ADR-018 and ADR-028
- Governing claims: `AG-010`, `AG-013`, `AG-014`, `AG-018`–`AG-020`,
  `MEM-018`–`MEM-023`

## Decision

Add one package-private, inert Explorer successor definition with new identities
`hive-agent:explorer:v2-shadow-1` and
`hive-agent-definition:explorer:v2-shadow-1`.

The successor extends the frozen Phase 2 Explorer candidate by reference. It binds
the unchanged base definition and projection, Generation Zero prompt, a typed
Explorer playbook, the three Phase 4A skills, context-selection policy and contract,
typed shadow output, opportunity admission boundary, and frozen lifecycle through
ordered content-addressed layers.

The definition distinguishes inherited requested capabilities from effective
capabilities. Effective capabilities and tool interfaces are empty. Activation is
`inert`, authority is `none`, and public release is false.

## Rejected alternatives

- Editing the Phase 2 canonical or generated Explorer is rejected because its
  `2-candidate` identity and bytes are judged compatibility evidence.
- Broadening `agent-definition-v2` or the Phase 2 generator is deferred because it
  changes all eight roles and the installed-resource contract.
- Reusing `hive-core` Explorer prose is rejected because it is quarantined,
  duplicative, and nonauthoritative.
- Runtime prompt rendering, engine binding, champion selection, and activation are
  deferred pending behavioral evaluation and a separate court.

## Migration and rollback

Migration adds only package-private Python contract/compiler modules, tests, and
evidence. No existing consumer imports or selects the successor.

Rollback removes the explicit compiler caller and new modules. Phase 2 canonical and
generated bytes, Generation Zero, Phase 4A, dissent, and court history remain.

## Limits

This decision can prove deterministic, drift-resistant canonical composition and
authority separation. It cannot prove curiosity, discovery quality, semantic
deduplication, customer value, token accuracy, learning, promotion readiness, or
superiority.
